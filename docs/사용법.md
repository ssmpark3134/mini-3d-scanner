# 간이 3D 스캐너 사용법

## 1. 실행 환경

PowerShell에서 `D:\opencv\miniprj`로 이동한다. 현재 기본 `python`은 없는 Python 3.14 경로를 가리켜 사용할 수 없다. 이 작업에서 프로젝트 내부에 준비한 Python을 다음과 같이 사용한다.

```powershell
cd D:\opencv\miniprj
.\.runtime\python\python.exe src/check_cameras.py
```

검사 결과는 `camera_report.json`에 저장된다. 번호별 열기와 프레임 읽기만 검사하며, CAM1=왼쪽/CAM2=정면/CAM3=오른쪽 대응은 직접 확인해야 한다. 기본 검사 번호는 0~5이며 `--devices 0 1 2 3 4 5 6 7`로 변경할 수 있다. 장치 3개 미만이면 종료 코드는 1이다.

다른 컴퓨터에서는 정상 설치된 Python으로 가상환경을 만들어 계획 문서의 명령을 사용할 수 있다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

이후 아래 명령의 `.\.runtime\python\python.exe`를 `.\.venv\Scripts\python.exe`로 바꾼다. 추가 런타임 라이브러리는 OpenCV, NumPy, Matplotlib만 사용한다. `.runtime`은 프로젝트 내부 실행 환경이며 다른 컴퓨터에 그대로 복사하기보다 새로 환경을 준비하는 편이 좋다.

## 2. 설정 만들기

```powershell
.\.runtime\python\python.exe src/capture.py --cameras 0 1 2 --write-config scanner_config.json
```

장치 번호는 실제 확인한 번호로 바꾼다. 생성된 JSON의 `cameras` 순서는 왼쪽, 정면, 오른쪽이다. 기존 설정 파일이 있으면 생성 명령은 덮어쓰지 않는다.

| 설정 | 의미 |
|---|---|
| `angle` | 카메라 위치 각도. 시작값 -45/0/+45도 |
| `cx`, `cy` | 물체 공통 원점이 보이는 원본 영상 픽셀 위치 |
| `scale` | 정규화 길이 1당 픽셀 수. 기준 막대 높이를 1로 정했다면 영상 속 막대 높이 |
| `threshold` | 흰 배경/어두운 물체 역이진화 임계값, 0~255 |
| `kernel` | 잡음 제거 커널 크기. 양의 홀수, 기본 3 |
| `roi` | `null` 또는 `[x,y,width,height]`. 원본 크기는 유지하며 영역 밖만 제거 |
| `focus_mode` | `unknown`, `fixed`, `manual`, `auto` |
| `focus_value` | 장치가 지원하는 수동 초점 값, 미확인은 `null` |
| `sharpness_confirmed` | 사용자가 실제 물체의 선명도를 확인한 뒤 `true`로 기록 |
| `bounds` | X/Y/Z 복원 범위. 기본 각각 [-1,1] |

카메라 높이와 방향을 고정하고 실제 물체에서 초점을 먼저 맞춘다. 초점 숫자는 장치별로 달라도 된다. 수동 초점 요청 반환값과 장치에서 읽은 원시 값은 저장되지만 실제 설정 성공·선명도를 보장하지 않는다. 지원되지 않는 장치는 카메라 앱 또는 렌즈로 직접 조절한다. 초점·줌·거리 변경 후 중심과 배율을 다시 확인한다.

## 3. 미리보기와 촬영

```powershell
.\.runtime\python\python.exe src/capture.py --cameras 0 1 2 --config scanner_config.json --output captures/scan_001
```

- `--width 640 --height 480`으로 입력 크기를 요청한다. 실제 크기는 화면과 저장 설정에 기록된다.
- 위쪽은 원본, 아래쪽은 마스크다. 빨간 십자는 설정한 공통 원점이다.
- 카메라 렌즈를 하나씩 가려 번호 대응을 확인하고 30초간 입력이 유지되는지 확인한다.
- 화면의 카메라별 Threshold 슬라이더로 마스크를 조절한다. 각도·중심·배율·ROI는 JSON을 수정한 뒤 재실행한다.
- `EMPTY`는 빈 마스크, `BORDER`는 영상 가장자리에 닿는 마스크다. 배경·조명·ROI를 조정한다.
- `S`: 현재 원본 3장, 마스크 3장, `config.json` 저장. 빈 마스크가 있으면 거부한다.
- `Q`, Esc 또는 창 닫기: 종료하고 카메라 해제.

기존 촬영 폴더가 있으면 시각을 붙인 새 폴더에 저장한다. 콘솔에 출력된 실제 저장 경로를 이후 복원 명령에 사용한다. 저장 실패 시 불완전한 폴더가 남을 수 있으며 마지막에 작성되는 `config.json`이 없는 폴더는 복원에 사용하지 않는다.

미리보기만 축소한다. 원본·마스크의 좌표는 보존한다. 저장 설정에 영상 크기가 있는 경우 실제 입력 크기와 다르면 중단하므로 투영값을 새 해상도에 맞춰 수정해야 한다. 일반 USB 순차 입력이므로 정지 물체만 촬영한다.

## 4. 복원과 다시 표시

```powershell
.\.runtime\python\python.exe src/reconstruct.py --input captures/scan_001 --grid 40 --output outputs/scan_001
.\.runtime\python\python.exe src/visualize.py --input outputs/scan_001/voxels.npy
```

복원은 `voxels.npy`, `result.png`, `metadata.json`을 만든다. 메타데이터에는 사용한 설정과 카메라별 잔여 복셀 수가 포함된다. 출력 폴더가 이미 있으면 중단하므로 재실행은 `outputs/scan_001_repeat`처럼 새 경로를 지정한다. 표시가 느리면 `--grid 24`를 사용한다. GUI 없이 이미지로만 표시하려면 다음 명령을 사용한다.

```powershell
.\.runtime\python\python.exe src/visualize.py --input outputs/scan_001/voxels.npy --no-show --save outputs/scan_001/view.png
```

## 5. 카메라 없이 합성 데모

```powershell
.\.runtime\python\python.exe -m unittest discover -s tests -v
.\.runtime\python\python.exe src/synthetic_demo.py --output captures/demo_new
.\.runtime\python\python.exe src/reconstruct.py --input captures/demo_new --grid 40 --output outputs/demo_new
```

이미 수행한 예제는 `captures/synthetic_box`, `outputs/synthetic_box`에 있다. 합성 상자의 실루엣을 이용한 알고리즘 검증이며 실제 스캔 결과가 아니다.

## 6. 한계와 문제 해결

- 카메라가 안 열리면 연결, Windows 카메라 권한, 다른 앱 점유, 장치 번호를 확인한다. 검사 도구는 DirectShow 후 Media Foundation을 시도한다.
- 결과가 비면 실루엣 반전, `cx/cy/scale`, 각도, 영상 크기부터 확인한다.
- 배경이나 그림자가 붙으면 조명과 ROI부터 조정한다. 가장 큰 연결 성분 하나를 남기므로 떨어진 여러 물체는 대상이 아니다.
- 세 방향 실루엣으로는 내부·가려진 오목면을 복원할 수 없다. 수동 직교투영이므로 정확한 치수 측정에 사용할 수 없다.
- 체커보드 보정은 후속 확장이다. 확장 시 내부 특성/왜곡과 공통 좌표계의 카메라 위치·방향을 함께 구해야 한다.
