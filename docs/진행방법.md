### 집에서 이어서 진행하기

저장소: https://github.com/ssmpark3134/mini-3d-scanner

처음 받는 경우 아래 명령으로 내려받고 환경을 설치한다.

```powershell
git clone https://github.com/ssmpark3134/mini-3d-scanner.git
cd mini-3d-scanner
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

1. [테스트방법](테스트방법.md)의 A에서 카메라 없이 합성 복원을 확인한다.
2. 집에서는 문서의 `.\.runtime\python\python.exe`를 `.\.venv\Scripts\python.exe`로 바꾸고 작업 경로도 내려받은 폴더로 바꾼다.
3. 카메라를 연결하면 B 순서대로 위 표의 실제 검증 4개 항목을 진행한다.
4. 확인한 결과만 이 문서와 PROJECT_PLAN.md에 기록한다. 코드 수정 시 관련 테스트를 다시 실행한다.

Python 환경, captures/, outputs/, 별도 tumblertest/ 폴더는 GitHub에 올리지 않았다. 합성 데이터는 스크립트로 다시 생성한다.

## 검증 결과

- 자동 테스트 7개 통과: 좌표축 투영, 합성 상자와 복셀 수 비증가, 빈 마스크, 영상 경계, 흰 마스크, 마스크 구멍 보존·빈 입력, 촬영 저장/재읽기와 배열 재현성.
- 합성 상자 40×40×40: 카메라별 잔여 복셀 수 25,152 → 14,832 → 11,040.
- `captures/synthetic_box/config.json`의 `input_type`은 `synthetic_box`로 기록한다.
- 실제 카메라 대응, 동시 입력, 초점 안정성, 실제 실루엣·복원은 완료로 판정하지 않았다.

## 실제 진행 순서

1. `docs/사용법.md`의 장치 검사 명령을 실행한다. 각 카메라가 프레임을 반환해야 다음 하드웨어 단계로 넘어간다.
2. 미리보기를 띄우고 렌즈를 하나씩 가려 CAM1 왼쪽, CAM2 정면, CAM3 오른쪽을 확인한다. 30초간 유지하고 종료도 확인한다.
3. 흰 배경과 무광 어두운 물체를 놓는다. 카메라 높이·각도·초점을 고정하고 공통 원점·기준 막대의 픽셀 높이를 설정한다.
4. 원본에서 물체 경계가 선명한지 확인한 뒤 임계값·ROI를 조절한다. 마스크가 비거나 가장자리에 닿지 않게 한다.
5. S로 저장하고 원본 3장과 마스크 3장을 직접 열어 비교한다. 저장 JSON의 초점 상태와 투영값도 확인한다.
6. 자동 테스트를 실행한 뒤 실제 저장 입력으로 복원한다. 카메라 조건 추가 시 복셀 수가 증가하지 않아야 한다.
7. 결과 형태를 실제 물체·실루엣과 비교한다. 복셀 수가 양수라는 사실만으로 성공 판정하지 않는다. 새 출력 경로로 재복원해 배열 재현성을 확인한다.
8. 확인한 단계만 계획 문서 체크리스트에 표시한다. 합성/실제 여부, 실패 원인, 다음 조치를 기록한다.

## 시간 배분

준비된 환경에서 0~10분 장치, 10~25분 미리보기, 25~40분 배치·초점, 40~60분 실루엣, 60~70분 저장, 70~95분 복원, 95~110분 표시·재실행, 110~120분 기록 순서다. 장치 문제가 있으면 가능한 파일 검증을 진행하되 실제 하드웨어 완료와 구분한다.

## 주요 파일

- `src/check_cameras.py`: 장치 검사
- `src/capture.py`: 설정 생성, 미리보기, 초점 요청, 저장
- `src/silhouette.py`: 실루엣 처리
- `src/reconstruct.py`: 투영과 복셀 교집합
- `src/visualize.py`: 표시와 PNG 저장
- `src/synthetic_demo.py`: 합성 상자 입력 생성
- `tests/test_projection.py`: 파일 기반 검증

추가 구조나 프레임워크 없이 함수 단위로 구현했다. 원본 문서와 촬영 데이터는 보존하며 `sources/`가 추가되면 읽기 전용 참고자료로 취급한다.
